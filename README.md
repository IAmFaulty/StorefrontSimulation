# How to Run:
1. Download all files as a Zip
2. Extract all files
3. Download Unityplayer.dll seperately
4. Put Unityplayer.dll in the same folder as all the other files
5. Run the .exe file

# How It's Made:
Tech used: C# and Unity Engine

I started from scratch, having never made a program in C# nor in Unity. I made the code assets myself after spending a few hours in the unredempting tutorial hell, and used the image assets from the Unity Game Store. Eventually, I got a prototype working that allows different customers to pass by the shop, with the next developments being to allow customers to enter the shop and make purchases, as well as an expected customer turnout to determine the final profits after comparing it to the overhead costs. Progress is still underway!

Note: It was later realized that customers didn't really need to pass by the shop (and it becomes an eye sore once the # of customers surpasses 50)

# Lessons Learned:
1. Never enter tutorial hell. It ended up wasting a lot of my time that I otherwise could've spent looking for answers and troubleshooting myself. Rarely did I find the answers without first prodding at the problem to see what was wrong in the first place, and that's what I've learned is better to do now.
2. Suffering is a great way to learn. It won't be enjoyable, but the bandaid will always hurt to take it off, y'know?
